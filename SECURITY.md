# Security Policy

## Supported versions

GAudio is currently pre-release. Before the first registry release, security fixes are provided for the current `main` branch. After publication begins, security fixes are provided for the newest published `0.x` release only.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/guoxk-me/gaudio/security/advisories/new). Do not open a public issue for an undisclosed vulnerability. Repository maintainers must keep private vulnerability reporting enabled so this channel remains available.

Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Maintainers will acknowledge a report within seven days and coordinate disclosure after a fix is available.

## Scope

Reports about GAudio source, npm artifacts, documentation infrastructure, and release automation are in scope. Vulnerabilities in optional peers should also be reported to the upstream project when the issue is not caused by GAudio integration.

# Project Records

The files in `plans/` and `specs/` preserve design and implementation history. Their checkboxes describe the state of the original planning session; they are not the current issue tracker.

Each record declares one of these statuses near its title:

- **Historical implementation record:** retained to explain why the shipped architecture exists.
- **Historical design record:** a point-in-time design whose exclusions can be superseded by later work.
- **Historical roadmap snapshot:** forward-looking proposals preserved for context but superseded by current source, tests, and public documentation.
- **Active roadmap:** forward-looking work that still requires explicit prioritization.

For current behavior, use the package source, tests, generated API declarations, and public documentation. For release history, use `packages/gaudio/CHANGELOG.md`.

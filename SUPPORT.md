# Support

Use the [GitHub Issues](https://github.com/guoxk-me/gaudio/issues) forms for usage questions, reproducible defects, and feature proposals. Choose the form that matches the request so maintainers receive the relevant environment details.

When a registry release is available, verify the issue against the newest `gaudio@next` version. Before the first registry release, reproduce it from the current `main` branch with the workspace package. Include:

- GAudio, browser, Node.js, and TypeScript versions as applicable.
- The active source protocol and optional adapter versions.
- A minimal reproduction and the emitted `GAudioError.code`.
- Relevant console output without credentials, signed URLs, or private media.

Security reports must follow [SECURITY.md](SECURITY.md) and must not be disclosed in public issues.
